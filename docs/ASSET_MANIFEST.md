# SKY REAPER asset manifest

Generated by `npm run art` (scripts/art/build.mjs). Do not edit by hand.
Runtime source of truth: `public/assets/manifest.json` (type `AssetManifest`, plus a `font` block with the bitmap grid).

## Conventions
- Strips are horizontal: `frames` x `frameW`, drawn at `PIXEL_SCALE` (2). KAPLAY sprite = key, `sliceX = frames`, anim `loop` when frames > 1.
- Player planes point **up**. Frames: 0 level, 1 bank left, 2 bank right (`fps 0`, not an animation).
- Skins: `player_<aircraft>_<skin>` (+ `_dmg`) for skin in arctic|desert|nightfall|crimson|tiger|gold, same 24x24 x 3 frames as the standard sprite (generated by `scripts/art/gen_skins.mjs`); `ui_skin_<skin>` 12x12 swatches (incl. `ui_skin_standard`).
- Enemy animation loops: the renderer plays any frame count (`frame = e.frame % frames`, fps from the manifest). Rotors 6f, radar dish 8f (full turn), afterburners/props/tracks/wakes 4f, missile-carrier bay doors 8f.
- Air enemies point **down** at angle 0 (renderer rotates by `facing - 90`). Ground units face down and are not rotated.
- `*_gun` overlays (turrets, tanks, boss turrets) point **down** at angle 0, pivot = sprite centre, matching the renderer's `angleToPlayer - 90`.
- Bullets point **up** at angle 0 (renderer uses `angle + 90`). `bullet_player_laser` / `ebullet_laser` tile vertically.
- FX frames are chosen by progress (0..1 over life), so fps there is only a hint.
- Ground units have a burnt `enemy_<id>_dead` wreck. Tiles are seamless 64x64 (_a/_b share a 6px edge ring). Animated water/grating tiles are calm 4-frame loops: static body, only a few soft crests/glints fade in, drift 1px/frame and fade out (about 1% of pixels change per frame; nothing flickers tile-wide). The citadel trace pulse steps 16px/frame in muted colours.
- Fonts (KAPLAY bitmap fonts, loaded from the manifest `fonts` array by src/assets/loader.ts; the old `font` block is kept for compatibility):
  - `sr_font` = `assets/sr_font.png`: original pixel font (scripts/art/gen_font.mjs), design cell 7x11 (5px glyphs, cap height 8, x-height 6, 2px descenders, true lowercase), white glyph + 1px dark outline. Tint with `color`.
  - `sr_font_outline` = `assets/sr_font_outline.png`: same glyphs, design cell 8x11, outline + 1px drop shadow down-right. For the UI agent: use it for HUD / text over gameplay or busy backgrounds. Same `size` => same glyph height (advance is 8/7 wider). It is registered only when its PNG loads, so fall back to `sr_font` when `k.getFont("sr_font_outline")` is null.
  - Atlases are stored at 2x (grid 14x22 / 16x22 texels, chars = printable ASCII 32..126, 16 per row) and loaded with a LINEAR filter so glyphs never drop rows/columns when the back buffer is below 1 px per game unit (phones, 1366x768).
  - `size` = design cell height (11; cap height = 8/11 of size). 1 design px = size/11 game units. Readable sizes: 11-12 minimum for body/HUD, 16-22 for headings, 33+ for titles. Below 11 the 1px strokes blur (never below 9). Multiples of 11 are pixel-perfect when the back buffer is at 1x.
  - Text width per char = size * 7/11 (sr_font) or size * 8/11 (sr_font_outline). Glyph test sheet: `assets_original/preview/font_test.png`.
- Audio: every SfxId / MusicId is runtime synth (`synth:<id>`), see src/assets/sfx.ts and music.ts.

## Merging a Kenney Pixel Shmup pack (optional)

kenney.nl blocks scripted downloads, so the build never fetches it. To use it: download the pack by hand,
unzip into `assets_original/kenney-pixel-shmup/`, create `assets_original/kenney-pixel-shmup/map.json`
mapping our keys to pack files, e.g. `{ "enemy_fighter_basic": ["Ships/ship_0001.png", "Ships/ship_0002.png"] }`,
then run `npm run art`. Mapped frames are centred into our frame size (`scripts/art/merge_kenney.mjs`); unmapped keys keep the original art.
Add the pack (CC0, Kenney, https://kenney.nl/assets/pixel-shmup) to ASSET_CREDITS.md.

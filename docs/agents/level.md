# LEVEL/CAMPAIGN agent brief — owns `src/levels/**`, `src/bosses/**`

Read `docs/agents/COMMON.md` first. The Enemy agent writes `docs/ENEMY_NOTES.md` and `bulletPresets` (src/patterns) early — use them when present; until then use ids from contracts/consts.ts and local fallback presets.

1. `src/levels/index.ts`: `levels: LevelModule` with 5 ChapterDefs (pacific, jungle, desert, arctic, citadel; ARCHITECTURE §3.5): palette, music id, scroll speed, 3–4 minute timelines (spawn / formation / banner / scroll / wind / weather / tutorial / pickup / boss), 3 objectives each (RunStats keys or `tag:<tag>`), rewards, medal thresholds. Chapter 1 teaches movement, air weapons vs air, bombs vs ground, the vulnerability bracket legend, flares vs missiles. Difficulty curve gentle → intense; air+ground mixed from ch2; line/vee/column/arc formations; special encounters (side ambush, drone minefield, sandstorm raid, convoy, armoured train). One file per chapter in `src/levels/chapters/`, with small builder helpers.
   `createRunner(id)` → LevelRunner: time-based events, weather (sandstorm: wind + visibility; blizzard: wind + snow), tutorial `hint`, `progress`.
   Backgrounds in `src/levels/backgrounds/`: tiled biome using `bgtile_<biome>_a|b`, decor `bgdeco_<biome>_1..8`, `bgcloud_1..3`; multiple parallax layers; animated water; deterministic decor placement hashed from scroll chunk (no Math.random in draw). If a sprite is missing, draw palette-coloured procedural fallback so every biome reads with zero assets. Low contrast so bullets stay readable; no per-frame allocations.
2. `src/bosses/index.ts`: `bosses: BossFactory` with 5 bosses per the §3.5 parts table. Define part EnemyDefs in `src/bosses/parts.ts` (`BOSS_PART_DEFS`, movement `scripted`, sprite `boss_<id>_<part>`), and register them at import time into `enemySystem.defs` (imported from ../enemies) via an exported `registerBossDefs(target)`; document it. ≥3 HP-threshold phases with distinct attacks, destructible parts that change attacks, telegraphs ≥800 ms, phase change → `bossPhase` event + clearEnemyBullets + shake/flash, defeat → chain explosions, `bossDefeated`, drops, `world.completeChapter()` after ~3 s. Use `patternRunner.start` from ../patterns. Music: `world.audio.playMusic('boss')`, final boss `'boss_final'`. `hud()` = live parts hp vs initial.
3. `docs/LEVEL_NOTES.md`: chapter outlines, timelines, boss phase tables, tuning knobs, sprite keys used. Append any new sprite key to `docs/ASSET_REQUESTS.md` immediately.
4. Verify with a timeline sanity script (monotonic t, ids exist, formation math), then playtest every chapter and boss in the browser once the Engine scene lands (`__sky.goto('game',{chapterId:'pacific',godMode:true})`).

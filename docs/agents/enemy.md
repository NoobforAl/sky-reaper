# ENEMY/AI agent brief — owns `src/enemies/**`, `src/patterns/**`

Read `docs/agents/COMMON.md` first.

1. `src/patterns/index.ts`: export `patternRunner: PatternRunner` and `PATTERNS: Record<string, PatternDef>`. Implement ALL PatternKinds (straight, aimed, spread, circular, spiral, burst, multi, homing, delayedBlast, areaStrike, sweep) with speed/count/spreadDeg/shots/gapMs/rotationDeg/aim (none|player|lead)/muzzles/telegraphMs. `start()` returns a PatternInstance that spawns via world.spawnBullet/spawnHazard, reads owner x/y/facing live each volley, plays `pattern.sfx` via world.playSfx, telegraphs via world.spawnFx, and for missiles emits `missileLaunched` (incrementing id) before spawning. Follow fairness rules (ARCHITECTURE §3.4). ~30 named reusable patterns at several difficulty levels. Export `bulletPresets` (visuals using ebullet_small|orb|needle|big|missile|bomb|flak, bright colours) — the Level agent reuses them for bosses.
2. `src/enemies/index.ts`: `enemySystem: EnemySystem` whose `defs` include every id in contracts/consts.ts (REQUIRED_AIR_ENEMIES, REQUIRED_GROUND_ENEMIES, EXTRA_ENEMIES) with sizes from ARCHITECTURE §3.3, vulnerability per §3.2, drops, explosion size, tags (radar, aa, naval, vehicle, structure, bomber...). Add ~6 original extras (e.g. sam_site, mine_layer, sand_crawler, ice_walker, shield_drone, gunship_light) and append each to `docs/ASSET_REQUESTS.md` (`key | size | frames | desc`) as soon as you decide it. Elite variants via defs only (tougher, recolour-friendly).
   Implement every movement kind in `src/enemies/movement.ts` (straight, sine, diagonal, circular, follow, formation with lone-survivor fallback, strafe, stationary, dive with telegraph, hover, scripted = no-op for bosses). Attack scheduling from AttackDef (interval, delay, minY/maxY, range); keep PatternInstances in `enemy.data`, cancel them in onDeath. Ground units apply only their OWN motion (Engine adds scroll). Turrets track the player via `facing`. Signature behaviours: kamikaze dive, missile carrier homing missiles, bomber carpet bombs with warnings, helicopter strafe/hover, radar buffs nearby fire rate, military base launches defenders. Readable and survivable.
3. Early (first third of your work): export `describeEnemy(id)` and write `docs/ENEMY_NOTES.md` listing every def (hp, layer, vulnerability, attacks, intended chapters). The Level agent depends on it; keep ids stable.
4. Test pure logic with a mock WorldAPI harness (tests/unit/enemies.*), then once the Engine's real game scene exists, watch enemies in the browser, tune and fix.
